# Tic-Tac-Toe Arena

A simple, colorful browser game created for a final-year ROSPL practical. Play classic 3×3 Tic-Tac-Toe against another player on the same device or challenge the computer.

## Objectives

- Build a working browser game with HTML, CSS, and JavaScript.
- Practice Git and GitHub collaboration through branches, commits, pull requests, and merges.
- Demonstrate readable, reusable, and open source project practices.

## Features

- Two-player local mode and computer mode
- Winner and draw detection
- Turn indicator, score tracking, restart, and reset-score controls
- Responsive dark interface with purple and blue accents
- No frameworks, database, authentication, API, or build step required

## How to Play

1. Open `index.html` in any modern web browser.
2. Choose between Two-Player Mode and Computer Mode.
3. Player X starts the game.
4. Click an empty cell to place your mark.
5. Players take turns placing X and O.
6. Align three marks horizontally, vertically, or diagonally to win.
7. If all nine cells are filled without a winner, the round ends in a draw.
8. Use the Restart button to play another round or Reset Score to clear the scores.

## Technologies

HTML5 · CSS3 · JavaScript · Git · GitHub · VS Code

## Setup

1. Clone or download the repository.
2. Open `index.html` directly in any modern browser, or use VS Code Live Server.
3. Select a mode and start playing.

## Rules

Players take turns placing X and O in the 3×3 grid. The first player to align three marks horizontally, vertically, or diagonally wins the round. If all nine cells are filled without a winning line, the round is a draw.

## GitHub Collaboration Practice

Create a repository, clone or fork it, then use feature branches such as `feature/computer-mode`. Make focused commits with messages like `Add winner detection`, push the branch, open and review a pull request, and merge it into `main`.

To practice conflict resolution, edit the same heading in two branches, pull the changes, resolve the conflict, commit the resolution, and push.
